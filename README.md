A comprehensive Tableau dashboard built to analyze the Netflix content library and uncover trends in content growth, genre distribution, country-wise availability, ratings, and title-level insights.

This project transforms a raw Netflix dataset into an interactive business intelligence dashboard that enables users to explore both high-level trends and detailed information about individual titles.

---

## Project Overview

As streaming platforms continue to expand globally, understanding content distribution and audience preferences has become increasingly important.

This project analyzes more than **6,000 Netflix titles** and presents meaningful insights through an interactive Tableau dashboard. The dashboard combines executive-level KPIs with detailed title information, allowing users to explore Netflix's content library from multiple perspectives.

The goal was not only to visualize data but also to create a dashboard that tells a clear business story and provides an intuitive user experience.

---

## Business Problem

Netflix offers thousands of movies and TV shows across different countries, genres, and audience categories. Extracting meaningful insights from such a large dataset can be difficult without effective visualization.

This dashboard was created to answer questions such as:

- How has Netflix's content library grown over time?
- Which countries contribute the most content?
- Which genres dominate the platform?
- What percentage of the catalog consists of Movies versus TV Shows?
- Which audience ratings are most common?
- How can users quickly explore detailed information about any title?

---

## Project Objectives

- Analyze content growth between **2008 and 2020**
- Compare Movies and TV Shows
- Identify major content-producing countries
- Explore genre distribution across the platform
- Analyze audience rating distribution
- Create an interactive dashboard for title-level exploration
- Present business insights in a clean and professional format

# Dashboard Features

## 1. Content Growth Over Time

**Visualization:** Area Chart

Tracks how Netflix expanded its content library over the years.

**Business Question**

> How has Netflix's content library grown from 2008 to 2020?

---

## 2. Country-wise Content Distribution

**Visualization:** Filled Map

Displays content availability across different countries.

**Business Question**

> Which countries contribute the most Netflix content?

---

## 3. Top 10 Genres

**Visualization:** Horizontal Bar Chart

Highlights the most popular genres available on Netflix.

**Business Question**

> Which genres dominate the platform?

---

## 4. Movies vs TV Shows

**Visualization:** Packed Bubble Chart

Shows the percentage split between Movies and TV Shows.

**Business Question**

> What proportion of Netflix's catalog consists of Movies compared to TV Shows?

---

## 5. Rating Distribution

**Visualization:** Bar Chart

Displays the distribution of audience ratings.

**Business Question**

> Which maturity ratings appear most frequently?

---

## Interactive Features

The dashboard includes interactive filters that make exploration simple and intuitive.

### Dynamic Type Filter

Users can switch between:

- Movies
- TV Shows

Selecting one automatically updates all related visualizations.

### Title-Level Analysis

After selecting a title, the dashboard instantly displays:

- Description
- Rating
- Duration
- Release Year
- Genre
- Type

This creates a smooth drill-down experience without navigating away from the dashboard.

# Key Insights

### Library Composition

- Movies account for approximately **68.4%** of the total catalog.
- TV Shows represent the remaining content.

### Audience Focus

- TV-MA is the most common rating.
- TV-14 is the second most common rating.

This indicates a stronger focus on mature audiences.

### Geographic Distribution

The United States contributes the largest share of Netflix content.

India also represents one of the platform's largest international content sources.

# Challenges Faced

## Handling Missing Data

Some records contained missing values in the Release Year field.

These values were filtered to maintain accurate visualizations.

---

## Dashboard Layout

Combining multiple worksheets into a single dashboard while maintaining readability required careful positioning of visual components using both tiled and floating layouts.
